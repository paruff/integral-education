## Design Rationale
Reference page format (not module). Positioned as capstone in Maps — the page that shows how everything connects. Uses the same MDX pattern as `ilp-practice-taxonomy.md` and `aqal-overview.mdx`.

## Page Structure

| Section | Content |
|---------|---------|
| Frontmatter | id, title, sidebar_label, description, tags |
| Introduction | What ILP is, why integration matters, cross-suite framing |
| Why Parallel Practice? | 3–4 paragraphs with synergy examples, ILP citation |
| 12-Week Integration Matrix | Full table: 12 weeks × 4 columns (State/Stage/Shadow/Community) |
| Community/Cohort Recommendation | Why cohort, cohort agreement template, Kegan/Mezirow citations |
| Synergies & Tensions | 5 specific interaction patterns with concrete examples |
| Cross-References | Links to QuickStarts, Facilitator Guides, ILP Taxonomy |
| Evidence & Citations | Tiered citation table |

## 12-Week Matrix Design

| Week | State Practice | Stage Work | Shadow Work | Community |
|------|---------------|------------|-------------|-----------|
| 1 | Gross state awareness (body scan) | Stage orientation module relevant to learner | Projection spotting foundation | Cohort formation: agreements, introductions |
| 2 | Gross state deepening | Continue stage module | Continue projection practice | Share one projection insight with cohort |
| ... | ... | ... | ... | ... |
| 12 | Integration week: personal practice architecture | Cross-stage reflection: what shifted? | Integration: shadow reclaimed as fuel | Cohort retrospective: what worked, what's next |

## Cohort Agreement Template
Basic template covering: purpose, confidentiality, meeting cadence, participation expectations, conflict protocol, right to pause/leave.
