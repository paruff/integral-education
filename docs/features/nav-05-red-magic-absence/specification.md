# NAV-05 · Confirm and document Red/Magic-Mythic content absence as an explicit scope boundary

## Problem Statement

The modules index confirms no content exists below Amber. This is expected and appropriate given the fork discussion (Red/Magic-Mythic work is planned as fork-specific), but the main site currently has **no explicit statement of this boundary**. A visitor whose centre of gravity is Red or earlier will find nothing addressed to them and no explanation of why.

## Requirements

### Functional
1. Add a short, honest scope note to the Modules index page (the generated-index description) explaining that content begins at Amber/Mythic
2. The note must acknowledge that earlier stages (Magic, Red) involve different developmental needs
3. The tone must be factual and non-apologetic — honest scoping, not a confession of failure
4. Optionally provide a signal that facilitator guidance or fork-specific content is forthcoming

### Non-functional
5. `npm run build` must pass
6. No new dependencies
7. No restructuring of the sidebar or module content

## Acceptance Criteria

| ID | Criterion | Test Type |
|----|-----------|-----------|
| AC-01 | Scope note appears on the Modules index page at `/docs/modules` | integration |
| AC-02 | Note states that content begins at Amber/Mythic stage | integration |
| AC-03 | Note acknowledges earlier stages (Magic, Red) involve different developmental needs | integration |
| AC-04 | Note tone is factual and non-apologetic | review |
| AC-05 | `npm run build` passes | build |

## Constraints

- No new files created if possible (modify existing description string in sidebars.js)
- No changes to module content (`.md`/`.mdx` files)
- No changes to AQAL Overview or other pages
- Scope must be confirmed by auditing the modules directory and sidebar

## Existing Context

- **Modules index**: `sidebars.js` lines 126-131 define the generated-index with `description: 'Browse standalone learning units across the integral curriculum.'`
- **Content audit**: All 75 modules in `docs/modules/` are at Amber level or above. No Red, Magic-Mythic, Beige, or Purple content exists
- **Sidebar**: "Stage Development" category starts at `amber-mythic-orientation` with no earlier-stage content
- **AQAL Overview**: Lists all stages (Beige through Turquoise) in the levels table but does not state which have content built
- **No `docs/modules/index.md`** exists — the page is auto-generated by the `generated-index` link type
