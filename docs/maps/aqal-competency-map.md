# AQAL Competency Map

This map defines measurable competencies for all quadrants, levels, lines, states, and types. Use it as the canonical design reference for pathway, assessment, and analytics decisions.

## How to Read This Map

- Competencies are organized by AQAL dimension.
- Each competency includes indicators and suggested evidence.
- Levels are progression bands, not rigid identity labels.

## Developmental Levels (Platform Working Model)

- `L1` Foundational: basic awareness and compliance.
- `L2` Differentiated: can distinguish and apply concepts in familiar contexts.
- `L3` Integrative: coordinates multiple perspectives and methods.
- `L4` Transformative: adapts and teaches across complex contexts.

## Quadrant Competency Matrix

| Quadrant | Competency Domain | L1 | L2 | L3 | L4 | Evidence Signals |
|---|---|---|---|---|---|---|
| I (Interior-Individual) | Self-awareness and regulation | Names present internal state | Uses regulation tools in routine stress | Chooses state-shifting practice contextually | Coaches others in state-aware practice design | Reflection quality, practice adherence, recovery time |
| We (Interior-Collective) | Perspective taking and dialogue | Identifies at least 2 valid perspectives | Engages in respectful disagreement | Synthesizes opposing views into a hybrid position | Facilitates plural dialogue with measurable learning gains | Forum discourse quality, peer feedback, synthesis artifacts |
| It (Exterior-Individual) | Skillful behavior and execution | Performs a defined behavior with guidance | Performs independently in stable scenarios | Adapts behavior under constraints | Designs repeatable behavioral protocols for teams | Performance task rubrics, observed behavior checklists |
| Its (Exterior-Collective) | Systems literacy and intervention | Identifies system components and roles | Maps feedback loops and delays | Designs leverage-point interventions | Evaluates system interventions with outcome metrics | System maps, intervention memos, impact review |

## Lines of Development

| Line | Competency Statement | Evidence Signals |
|---|---|---|
| Cognitive | Uses evidence and reasoning appropriate to task complexity | Claim quality, source validity, causal reasoning score |
| Emotional | Differentiates emotions and regulates constructively | Emotional granularity score, self-regulation logs |
| Moral | Makes transparent value tradeoffs with stakeholder awareness | Ethical reasoning memo, dilemma analysis rubric |
| Interpersonal | Collaborates productively across differences | Peer ratings, conflict-resolution outcomes |
| Somatic | Uses body-based practices for attention and resilience | Practice completion, physiological self-report trends |
| Spiritual/Meaning | Articulates meaning frameworks without dogmatism | Reflection depth, perspective integration quality |

## States Competency Framework

| State Target | Baseline Competency | Intermediate Competency | Advanced Competency | Safety Note |
|---|---|---|---|---|
| Focused attention | Sustain attention for a short task window | Recover attention after distraction | Select state-shifting protocol by context | Avoid overloading with long practice duration early |
| Open monitoring | Observe thoughts/emotions without immediate reaction | Identify recurring patterns and triggers | Integrate insight into behavior change plans | Include grounding and stop options |
| Compassion/prosocial | Generate prosocial intent in low-stakes contexts | Apply empathy in active disagreement | Facilitate constructive repair in conflict | Monitor emotional overexertion |
| Contemplative depth | Follow guided stillness safely | Report meaningful insight with integration notes | Apply insight to ethical/systemic action | Requires contraindication and support guidance |

## Types Adaptation Matrix

| Type Dimension | Design Adaptation Rule |
|---|---|
| Introversion-Extraversion | Provide both solo reflection and social processing options |
| Structure-Seeking vs Exploratory | Offer guided pathway and optional branching pathway |
| Analytical vs Relational preference | Pair logic-first and narrative-first representations |
| Time-constrained professionals | Default microlearning sequence with optional deep dives |

## Competency-to-Assessment Mapping

- Use performance-based assessments for L2+ outcomes.
- Use retrieval checks for concept durability.
- Use rubric criteria tied to explicit AQAL dimensions.
- Grade high-judgment work with blind-review where feasible.

## Minimum Metadata Required for New Modules

- Primary AQAL tags (quadrant, level, line, state, type adaptation)
- Target competency statements
- Performance evidence expected
- Retrieval schedule design
- Safety and accessibility notes

## Acceptance Gate for Publication

A module is launch-ready only if it passes all checks:

- Competencies clearly mapped to AQAL dimensions.
- Assessment evidence aligns with competency claims.
- Retrieval and spacing loop is present.
- Accessibility and safety notes are complete.
