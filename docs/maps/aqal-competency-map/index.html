AQAL Competency Map

This map defines measurable competencies for all quadrants, levels, lines, states, and types. Use it as the canonical design reference for pathway, assessment, and analytics decisions.

How to Read This Map​

  • Competencies are organized by AQAL dimension.
  • Each competency includes indicators and suggested evidence.
  • Levels are progression bands, not rigid identity labels.

Developmental Levels (Platform Working Model)​

  • L1 Foundational: basic awareness and compliance.
  • L2 Differentiated: can distinguish and apply concepts in familiar contexts.
  • L3 Integrative: coordinates multiple perspectives and methods.
  • L4 Transformative: adapts and teaches across complex contexts.

Competency-to-Assessment Mapping​

  • Use performance-based assessments for L2+ outcomes.
  • Use retrieval checks for concept durability.
  • Use rubric criteria tied to explicit AQAL dimensions.
  • Grade high-judgment work with blind-review where feasible.

Minimum Metadata Required for New Modules​

  • Primary AQAL tags (quadrant, level, line, state, type adaptation)
  • Target competency statements
  • Performance evidence expected
  • Retrieval schedule design
  • Safety and accessibility notes

Acceptance Gate for Publication​

A module is launch-ready only if it passes all checks:

  • Competencies clearly mapped to AQAL dimensions.
  • Assessment evidence aligns with competency claims.
  • Retrieval and spacing loop is present.
  • Accessibility and safety notes are complete.
