# AQAL Label Crosswalk (Dual-Layer)

This guide defines a dual-layer language model for learner accessibility and conceptual precision.

- Layer A: learner-friendly labels for onboarding and usability.
- Layer B: canonical AQAL terms for rigor and interoperability.

Use both layers together where useful, for example: "Skills (Lines)" or "Style (Types)".

## Why Dual-Layer

- Improves accessibility for new learners.
- Preserves theoretical accuracy for advanced users and contributors.
- Creates consistent terminology across modules, pathways, and issues.

## Canonical Crosswalk

| Friendly Label | Canonical AQAL Term | Preferred Display |
|---|---|---|
| Where | Quadrants | Where (Quadrants) |
| Depth | Levels | Depth (Levels) |
| Skills | Lines | Skills (Lines) |
| Experience | States | Experience (States) |
| Style | Types | Style (Types) |

## 4-Path Crosswalk (Optional)

The 4-path language is recommended as an editorial accessibility layer, not a mandatory framework.

| Friendly Path | Primary AQAL Alignment | Typical Emphasis |
|---|---|---|
| Growing Up | Levels (and Lines) | Developmental complexity, meaning-making, perspective expansion |
| Waking Up | States | Awareness practices, contemplation, state access and stabilization |
| Cleaning Up | Shadow work (I/We), emotional/interpersonal lines | Projection work, triggers, integration, repair |
| Showing Up | Quadrants in action (especially It/Its and We) | Ethical participation, service, contribution, systems behavior |

## Editorial Guidance by Audience Readiness

### For Amber-oriented learners

Use strengths-first framing:

- Lead with reliability, responsibility, role clarity, and service.
- Frame rational methods as strengthening good order, not replacing it.
- Prefer concrete examples and clear steps.

Suggested style:

- "Skills (Lines) you can practice"
- "Style (Types) preferences"
- "Where (Quadrants) to apply this in real life"

Avoid:

- Deficit framing (for example "you are stuck at...")
- Jargon-only explanations without practical translation

### For Orange/Green/Integral audiences

- Increase canonical terminology density.
- Keep dual-layer phrasing in headings on first introduction.
- Shift to canonical shorthand after orientation is established.

## Application Rules for Contributors

- Use dual-layer labels in intros, pathway overviews, and onboarding screens.
- In advanced modules, canonical AQAL terms can dominate after first-pass orientation.
- 4-path framing is optional and should be used when it improves clarity for target learners.
- If used, map each selected path to at least one explicit AQAL dimension.

## Recommended Tags (Dual-Layer)

For future content tagging, use both topical and dual-layer tags where relevant:

- Canonical tags: `quadrants`, `levels`, `lines`, `states`, `types`
- Friendly tags: `where`, `depth`, `skills`, `experience`, `style`
- Optional path tags: `growing-up`, `waking-up`, `cleaning-up`, `showing-up`

## Quick Authoring Snippet

Use this pattern in learner-facing docs:

- Where (Quadrants): I / We / It / Its
- Depth (Levels): Amber -> Orange (example)
- Skills (Lines): cognitive, emotional
- Experience (States): focused attention, reflection
- Style (Types): structured-first, discussion-first

If using 4-path framing:

- Growing Up: complexity and perspective tasks
- Waking Up: awareness/state practices
- Cleaning Up: trigger/projection integration
- Showing Up: service/ethics/systems participation
