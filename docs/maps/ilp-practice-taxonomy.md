## ILP Practice Taxonomy

This taxonomy defines Integral Life Practice (ILP) categories, taxonomy dimensions, progression ladders, fallback alternatives, and safety constraints for implementation in learning pathways and curriculum design.

Canonical references:

- [AQAL Label Crosswalk](../maps/aqal-label-crosswalk)
- [Shadowwork Safety Standard](/internal/safety/shadowwork-safety-standard)
- [Instructional Design Protocol](/internal/quality/instructional-design-protocol)

## 1. Practice Families Overview

| Family | Primary Aim | Typical Formats | AQAL Primary Quadrant |
|---|---|---|---|
| Body | Regulation, vitality, embodiment | Breathwork, mobility, posture resets, walking practice | It (Upper-Right) |
| Somatic | Interoceptive awareness, nervous system regulation, embodied presence | Grounding, body scan, breath awareness, co-regulation | I / It (Upper-Left + Upper-Right) |
| Mind | Attention and cognition | Focus drills, bias checks, metacognitive journaling | I (Upper-Left) |
| Spirit/Meaning | Perspective widening and meaning coherence | Contemplative sits, gratitude, values reflection | I (Upper-Left) |
| Shadow | Projection awareness and integration | Trigger logs, role reversal, parts dialogue | I / We |
| Ethics | Values-in-action and responsibility | Dilemma analysis, commitment contracts | We (Lower-Left) |
| Relationships | Empathy and conflict skill | Dialogue protocols, feedback exchange | We (Lower-Left) |
| Service | Contribution beyond self-interest | Community projects, mentorship micro-actions | Its (Lower-Right) |

## 2. Taxonomy Dimensions

All practices are described along five standard dimensions.

| Dimension | Allowed Values |
|---|---|
| Duration band | Short (3–5 min), Medium (10–15 min), Long (20–30 min), Extended (30+ min) |
| Intensity | Low, Moderate, High |
| Mode | Solo, Pair, Group, Facilitated |
| Evidence type | Self-report, peer feedback, performance artifact, facilitator observation |
| Risk profile | Low, Medium, Elevated |

### 2.1 Body

| Dimension | Values |
|---|---|
| Duration bands | Short (3–5 min): micro-resets, breath anchors; Medium (10–15 min): mobility flows, walking practice; Long (20–30 min): yoga, structured movement |
| Intensity levels | Low: seated breath or gentle stretch; Moderate: sustained movement or bodyweight sequence; High: vigorous aerobic or advanced postural work |
| Contraindications | Recent injury or surgery; chronic pain without practitioner guidance; cardiovascular contraindications for high-intensity formats |
| Setup requirements | Quiet space with room to move; comfortable clothing; no equipment required for Low/Medium; mat recommended for Long |

### 2.1b Somatic

**Definition:** Practices that develop interoceptive awareness, nervous system regulation, and embodied presence — distinct from Body practices (physical conditioning) and Mind practices (cognitive reflection). The somatic line is the infrastructure all other developmental lines rest on.

| Dimension | Values |
|---|---|
| Duration bands | Short (2–5 min): grounding, single breath exercise; Medium (10–15 min): body scan, progressive relaxation; Long (20–30 min): full somatic practice session with integration time |
| Intensity levels | Low: seated check-in (name one sensation); Moderate: guided body scan or movement-based regulation; High: trauma-adjacent material, partner co-regulation, or extended interoceptive tracking |
| Contraindications | Active trauma history without practitioner support; dissociation or depersonalisation patterns; body-image disorders; recent somatic practice-related destabilisation. Label these practices as facilitator-recommended minimum (Tier 2). |
| Setup requirements | Quiet space with option to sit or lie down; comfortable, non-restrictive clothing; facilitator present for Tier 2 practices; grounding resources immediately accessible |
| Stage/Tier requirements | **Tier 1 (solo-safe):** grounding, breath awareness (without prescribed ratios — see SAFE-03), naming one body sensation. **Tier 2 (facilitator-recommended minimum):** body scan, progressive relaxation, co-regulation partner exercise. **Tier 3 (facilitator-required):** trauma-adjacent somatic work, extended interoceptive tracking with history of dissociation. |
| Practice catalogue | Grounding (feet on floor, name 5 things visible, slow breath); Breath awareness (notice natural breath rhythm, no prescribed counts); Body scan (guided, region-by-region — see SOM-01 Practice section); Movement-based regulation (gentle shaking, stretching, walking meditation); Co-regulation practice (partner breathing, shared grounding — facilitator present for initial sessions) |
| Cross-references | [Somatic Line Overview](../modules/somatic-line-overview) (SOM-01); [Shadowwork Safety Standard](/internal/safety/shadowwork-safety-standard); SAFE-03 (no prescribed breath-count ratios) |

### 2.2 Mind

| Dimension | Values |
|---|---|
| Duration bands | Short (3–5 min): single-focus drill, bias prompt; Medium (10–15 min): metacognitive journal, systems mapping; Long (20–30 min): in-depth reflection or argument analysis |
| Intensity levels | Low: reading or single-prompt response; Moderate: multi-step analysis or debate review; High: extended cognitive reframing or belief examination |
| Contraindications | Acute cognitive overload or burnout states; neurological conditions affecting sustained attention (modify pacing, do not exclude) |
| Setup requirements | Quiet environment; writing surface or digital note space; distraction-free window |

### 2.3 Spirit/Meaning

| Dimension | Values |
|---|---|
| Duration bands | Short (3–5 min): gratitude noting, values word; Medium (10–15 min): contemplative sit, loving-kindness; Long (20–30 min): extended sit, nature immersion, meaning mapping |
| Intensity levels | Low: informal gratitude or appreciation; Moderate: structured contemplative sit with breath focus; High: open-awareness sit, inquiry practices, extended silence |
| Contraindications | Acute anxiety or panic history (modify high-intensity entry; begin with eyes-open or movement-based forms); dissociative tendencies (require facilitator guidance for High); recent significant loss (offer grief-adapted alternatives) |
| Setup requirements | Comfortable seated position; optional timer or guidance audio; limited external distraction; written reflection prompt available |

### 2.4 Shadow

| Dimension | Values |
|---|---|
| Duration bands | Short (3–5 min): trigger noting, reactive emotion log; Medium (10–15 min): trigger pattern journaling, projection check; Long (20–30 min): structured parts dialogue, role reversal |
| Intensity levels | Low: noticing and naming a reactive emotion without exploration; Moderate: structured journaling to identify projection or assumption; High: active parts dialogue, role-reversal, or inner critic confrontation |
| Contraindications | Active trauma response or crisis state; unmanaged PTSD symptoms; no active support system; inability to self-regulate during reflective activities |
| Setup requirements | Private, safe physical environment; written prompt sheet; grounding script on hand; facilitator access for Moderate/High; explicit consent completed before practice |

### 2.5 Ethics

| Dimension | Values |
|---|---|
| Duration bands | Short (3–5 min): single-value check-in; Medium (10–15 min): dilemma analysis; Long (20–30 min): commitment contract, stakeholder impact mapping |
| Intensity levels | Low: personal values recall; Moderate: structured ethical dilemma analysis; High: live commitment declaration or accountability partnership |
| Contraindications | Contexts with active interpersonal conflicts that require mediation beyond peer scope; high-stakes legal or employment situations (defer to qualified guidance) |
| Setup requirements | Scenario prompt or real-life dilemma description; writing space; optional partner for accountability formats |

### 2.6 Relationships

| Dimension | Values |
|---|---|
| Duration bands | Short (3–5 min): appreciation or acknowledgment exchange; Medium (10–15 min): structured dialogue or feedback session; Long (20–30 min): interpersonal repair protocol, perspective-taking exercise |
| Intensity levels | Low: one-way appreciation or written reflection on a relationship; Moderate: structured dialogue with a partner using an agreed protocol; High: conflict repair or difficult conversation with facilitator framing |
| Contraindications | Active abusive or unsafe relationships (refer to qualified support, do not use platform practices as substitute); power imbalances that undermine voluntary participation |
| Setup requirements | Willing partner or peer; agreed dialogue ground rules; optional facilitator presence for High-intensity formats; private or semi-private environment |

### 2.7 Service

| Dimension | Values |
|---|---|
| Duration bands | Short (3–5 min): micro-action planning (identify one contribution); Medium (10–15 min): mentorship exchange or community contribution reflection; Long (20–30 min): community project session or service learning debrief |
| Intensity levels | Low: planning a small contribution; Moderate: completing a defined service task and reflecting; High: sustained community role or public commitment |
| Contraindications | Overextension or burnout risk—learners in high-demand life circumstances should start at Low; avoid high-stakes public commitments without adequate preparation |
| Setup requirements | Identified contribution context; reflection prompt; optional partner or community group; Low intensity requires no external resources |

## 3. Progression Ladders and Fallback Alternatives

Each ladder covers **Levels 1–4** (Beginner → Advanced). Criteria for advancing between levels are explicit. Fallback alternatives are provided for learners with constraints.

### 3.1 Body

| Level | Name | Criteria to Enter | Example Practices | Developmental Line Focus |
|---|---|---|---|---|
| 1 | Foundation | No prior somatic practice needed | 3-min seated breath reset, gentle neck rolls | Somatic awareness |
| 2 | Consistent Mover | Completed Level 1 practices for 5+ sessions | 10-min walking meditation, basic mobility flow | Somatic + Emotional regulation |
| 3 | Embodied Practitioner | Consistent 10-min practice for 3+ weeks | 20-min yoga or bodyweight sequence, breath-body linking | Somatic + Cognitive integration |
| 4 | Integrated Practice | Spontaneous somatic self-regulation reported | 30-min vigorous movement, advanced postural or aerobic work | Somatic + Interpersonal presence |

**Criteria for advancing:** Demonstrate the target practice independently for 5+ sessions before progressing. Self-reported skill and reflection artifact required.

**Fallback alternatives:** Learners with mobility limitations use seated or reclined breath-based practices at any level. Reduce duration before intensity.

---

### 3.1b Somatic

| Level | Name | Criteria to Enter | Example Practices | Developmental Line Focus |
|---|---|---|---|---|
| 1 | Body-Aware | No prior practice needed | Grounding (feet on floor, slow breath, name 5 things visible); name one body sensation | Somatic awareness |
| 2 | Self-Regulating | Completed Level 1 for 5+ sessions; can identify regulation state (regulated/hyper/hypo) | Guided body scan (10 min); breath awareness without prescribed ratios; gentle movement-based regulation | Somatic + Emotional regulation |
| 3 | Somatically Integrated | Consistent body scan practice for 3+ weeks; uses body signals during decisions | Progressive relaxation; interoceptive tracking during conversation; co-regulation with partner | Somatic + Cognitive + Interpersonal |
| 4 | Embodied Facilitator | Spontaneous somatic self-regulation; teaches or designs body-informed protocols | Leading group grounding; designing body check-in protocols; evaluating participant somatic change | Somatic + Facilitation + Systemic design |

**Criteria for advancing:** Demonstrate target practice independently for 5+ sessions at Current Level. Facilitator present for Level 3+ partner practices.

**Fallback alternatives:** Learners with trauma history use grounding only at Level 1; progress to body scan only with facilitator present. No prescribed breath-count ratios at any level (per SAFE-03). Reduce duration before intensity; stop if dissociative response occurs.

---

### 3.2 Mind

| Level | Name | Criteria to Enter | Example Practices | Developmental Line Focus |
|---|---|---|---|---|
| 1 | Awareness Starter | No prior metacognitive training needed | Single-prompt thought log, one cognitive bias named | Cognitive awareness |
| 2 | Pattern Recognizer | Completed 3+ Level 1 reflections | Weekly bias journal, simple systems map sketch | Cognitive + Metacognitive |
| 3 | Critical Analyst | Demonstrated consistent journaling with evidence | Structured argument analysis, multi-perspective mapping | Cognitive + Moral reasoning |
| 4 | Integrative Thinker | Applies multiple frameworks spontaneously | Extended belief examination, cross-domain reasoning task | Cognitive + Interpersonal |

**Criteria for advancing:** Submit at least one reflection artifact showing the new skill before progressing. Facilitate peer review at Levels 3–4.

**Fallback alternatives:** For learners with cognitive fatigue, allow audio-prompt responses instead of written reflection. Reduce prompt complexity rather than skipping the practice.

---

### 3.3 Spirit/Meaning

| Level | Name | Criteria to Enter | Example Practices | Developmental Line Focus |
|---|---|---|---|---|
| 1 | Meaning Noticer | No prior contemplative experience needed | 3-min gratitude noting, values word selection | Spiritual/Meaning |
| 2 | Contemplative Beginner | Completed 3+ Level 1 practices | 10-min guided breath sit, loving-kindness reflection | Spiritual + Emotional |
| 3 | Regular Practitioner | Consistent 10-min sits for 2+ weeks | 20-min unguided sit, values-in-action mapping | Spiritual + Cognitive |
| 4 | Inquiry Practitioner | Self-sustained sitting practice | Extended open-awareness sit, self-inquiry, nature immersion | Spiritual + Interpersonal presence |

**Criteria for advancing:** Reflection journal entry demonstrating quality of attention before progressing. For Level 4, facilitator check-in recommended.

**Fallback alternatives:** For learners with anxiety or high cognitive arousal, use walking or movement-based contemplative forms (eyes open, gentle pace) instead of seated silence. Eyes-open sitting (soft gaze, upright posture, no closed-eye instruction) is also an appropriate lower-intensity alternative at any level. Loving-kindness reflection (silently directing goodwill phrases toward self and others) is lower intensity than open-awareness sits and suitable for most Level 2 learners.

---

### 3.4 Shadow

> **[HUMAN-REQUIRED]** Safety boundaries for this ladder must be reviewed and approved by a qualified SME before use in live cohorts. See [Shadowwork Safety Standard](/internal/safety/shadowwork-safety-standard).

| Level | Name | Criteria to Enter | Example Practices | Developmental Line Focus |
|---|---|---|---|---|
| 1 | Aware Observer | Completed baseline regulation practice; explicit consent given | Reactive emotion log (name + situation only), trigger frequency noting | Emotional + Cognitive |
| 2 | Pattern Investigator | Consistent Level 1 practice for 1+ week; self-regulation skill demonstrated | Projection check journal (who irritates me and what it might reflect), assumption mapping | Emotional + Interpersonal |
| 3 | Parts Explorer | Demonstrated stable self-observation at Level 2; distress check passed | Structured parts dialogue (written), role-reversal thought experiment | Emotional + Moral |
| 4 | Integration Practitioner | Facilitator approval; sustained stability across Level 3 practices | Active inner-critic negotiation, interpersonal repair using shadow insight | Emotional + Interpersonal + Moral |

**Criteria for advancing:** Distress check-in required before each level transition. Level 3–4 transitions require facilitator review. Stop rules apply at all levels.

**Fallback alternatives:**
- If Level 2 produces destabilization: return to Level 1 trigger noting only.
- If Level 3 is inaccessible: substitute with cognitive reframing (Mind family) until regulation is stable.
- Always offer sensory grounding as an exit from any shadow practice.

**Stop rules:** Stop immediately if escalating panic, dissociation, inability to orient, or risk expression to self or others is present. Refer to [Shadowwork Safety Standard](/internal/safety/shadowwork-safety-standard).

---

### 3.5 Ethics

| Level | Name | Criteria to Enter | Example Practices | Developmental Line Focus |
|---|---|---|---|---|
| 1 | Values Identifier | No prerequisites | Personal values list, single-value check-in | Moral awareness |
| 2 | Dilemma Analyst | Completed 2+ Level 1 practices | Structured ethical dilemma analysis, stakeholder identification | Moral + Cognitive |
| 3 | Commitment Practitioner | Demonstrated dilemma analysis with documented reasoning | Commitment contract with accountability partner, values-action gap audit | Moral + Interpersonal |
| 4 | Ethical Leader | Active accountability partnership for 4+ weeks | Community dilemma facilitation, ethical policy analysis | Moral + Interpersonal + Systems |

**Criteria for advancing:** Completed written artifact demonstrating the skill before progressing. Level 3–4 requires peer or facilitator acknowledgment.

**Fallback alternatives:** Learners uncomfortable with partner formats use solo written commitment at Level 3. Scale community scope down at Level 4 for those with limited community access.

---

### 3.6 Relationships

| Level | Name | Criteria to Enter | Example Practices | Developmental Line Focus |
|---|---|---|---|---|
| 1 | Appreciation Practitioner | No prerequisites | Written appreciation or gratitude to another person, acknowledgment note | Interpersonal + Emotional |
| 2 | Active Listener | Completed 2+ Level 1 practices | Structured listening exercise, reflective response practice | Interpersonal + Cognitive |
| 3 | Dialogue Partner | Demonstrated listening skills across 2+ sessions | Full structured dialogue protocol with a peer, perspective-taking exercise | Interpersonal + Moral |
| 4 | Repair and Renewal | Stable Level 3 skill; willing partner present | Difficult conversation protocol, interpersonal repair sequence | Interpersonal + Moral + Emotional |

**Criteria for advancing:** Partner confirmation of experience quality required at Levels 3–4. Facilitator framing available but not required at Level 3; recommended at Level 4.

**Fallback alternatives:** For learners without an available partner, use written perspective-taking exercises or recorded dialogue review at Levels 2–3. Reduce scope of repair at Level 4 rather than skipping entirely.

---

### 3.7 Service

| Level | Name | Criteria to Enter | Example Practices | Developmental Line Focus |
|---|---|---|---|---|
| 1 | Contribution Planner | No prerequisites | Identify one micro-contribution; write what, where, when | Moral + Systems awareness |
| 2 | Active Contributor | Completed at least one Level 1 contribution | Complete a defined service task; reflect on impact | Moral + Interpersonal |
| 3 | Consistent Servant | Sustained contributions for 3+ weeks | Mentorship exchange, ongoing community role | Moral + Interpersonal + Cognitive |
| 4 | Systems Change Agent | Demonstrated sustained service commitment | Community project leadership, public advocacy action | Moral + Systems + Interpersonal |

**Criteria for advancing:** Reflection artifact documenting the contribution and learning before progressing.

**Fallback alternatives:** For learners with time or capacity constraints, reduce contribution scope at all levels rather than skipping. Solo reflection on contribution opportunities is a valid Level 1 starting point.

## 4. Safety Boundaries for Shadow and Contemplative Practices

> **[HUMAN-REQUIRED]** This section must be reviewed and approved by a qualified SME (mental health or trauma-informed practice professional) before publication or cohort use. Copilot output is a draft for human validation only.

### 4.1 Shadow Practice Safety Boundaries

| Boundary | Specification |
|---|---|
| Consent | Explicit informed consent required before any shadow practice begins. Consent must be renewed when advancing levels. |
| Tier classification | Level 1 = Tier 1 (self-guided allowed). Level 2 = Tier 1 with safety prompts. Level 3 = Tier 2 (facilitator-supervised recommended). Level 4 = Tier 3 (facilitator-led only). |
| Entry check | Distress check-in required at session start. Learner must report current emotional state before proceeding. |
| Stop rules | Escalating panic, dissociation, inability to orient, or any expression of risk to self or others requires immediate stop. Shift to grounding protocol. |
| Grounding menu | Breath anchor (4-count inhale, 6-count exhale), sensory orientation (5 senses named), physical movement reset (shake or walk). |
| Escalation path | Level 1 incidents: document and monitor. Level 2–3 incidents: notify facilitator and require follow-up check. Any crisis expression: immediate handoff to qualified human support. |
| Contraindications | Active trauma response or crisis state; unmanaged PTSD; no active support system; history of repeated destabilization during reflective practice without support plan. |

### 4.2 Contemplative (Spirit/Meaning) Practice Safety Boundaries

| Boundary | Specification |
|---|---|
| Anxiety and panic | Learners with history of panic attacks begin with movement-based or eyes-open contemplative forms only. Closed-eye sitting at Level 3+ only with facilitator awareness. |
| Dissociation | Learners with dissociative tendencies require facilitator guidance before attempting High-intensity contemplative formats. Open-awareness sits are contraindicated without qualified oversight. |
| Grief and loss | Offer grief-adapted alternatives (e.g., self-compassion reflection instead of extended silence) when learner discloses recent significant loss. |
| Spiritual emergence | If a learner reports unusual or destabilizing perceptual experiences during contemplative practice, pause immediately and refer to facilitator or qualified support. Do not encourage continuation without assessment. |
| Duration limits | No self-guided session at Level 1–2 should exceed 15 minutes. Extended practices at Level 3–4 require explicit readiness check. |
| Stop rules | Inability to return to ordinary awareness within 3 minutes of practice end; panic response; overwhelming emotional flooding. |

## 6. Practice Card Template

Each practice implementation must define the following fields:

| Field | Description |
|---|---|
| Practice ID | Unique identifier (e.g., ILP-BODY-001) |
| Family | One of: Body, Mind, Spirit/Meaning, Shadow, Ethics, Relationships, Service |
| AQAL tags | Quadrant(s), Level, Line(s), State, Type notes |
| Duration | Short / Medium / Long / Extended |
| Intensity | Low / Moderate / High |
| Tier | 1 / 2 / 3 (safety tier; applies to Shadow and Spirit/Meaning practices per [Shadowwork Safety Standard](/internal/safety/shadowwork-safety-standard); mark N/A for Body, Mind, Ethics, Relationships, and Service practices unless emotionally elevated) |
| Instructions | Step-by-step learner-facing directions |
| Reflection prompt | Open-ended prompt for post-practice journaling |
| Evidence capture | Method for documenting completion |
| Safety notes | Contraindications and stop rules specific to this practice |
| Fallback practice | Lower-intensity or lower-duration alternative |
| Escalation trigger | Condition requiring facilitator or support contact |

## 8. Scheduling Guidelines

- Pair each concept lesson with one short practice from the relevant family.
- Insert retrieval prompts 24 h, 72 h, and 7 d after initial exposure.
- Alternate families across weeks to support interleaving.
- Keep High-intensity and Tier 2–3 practices in Facilitated mode.
- Do not schedule Shadow practices in the first week of any new cohort.
- Sequence Body or Mind practices before Shadow or Spirit practices in any single session.

---

## 9. Assessment Integration

- Use short formative checks for all practice families.
- Use performance tasks for Ethics, Relationships, and Systems transfer.
- Use structured reflections for Spirit/Meaning and Shadow integration.
- Require rubric alignment before grading.
- All High-intensity or Elevated-risk practices require facilitator observation as the primary evidence type.
