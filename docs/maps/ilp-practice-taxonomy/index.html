ILP Practice Taxonomy

This taxonomy defines Integral Life Practice categories, progression, and safety constraints for implementation in learning pathways.

Practice Families​

FamilyPrimary AimTypical Formats
BodyRegulation, vitality, embodimentBreathwork, mobility, posture resets, walking practice
MindAttention and cognitionFocus drills, bias checks, metacognitive journaling
Spirit/MeaningPerspective widening and meaning coherenceContemplative sits, gratitude, values reflection
ShadowProjection awareness and integrationTrigger logs, role reversal, parts dialogue
EthicsValues-in-action and responsibilityDilemma analysis, commitment contracts
RelationshipsEmpathy and conflict skillDialogue protocols, feedback exchange
ServiceContribution beyond self-interestCommunity projects, mentorship micro-actions

Delivery Dimensions​

DimensionAllowed Values
Duration band3-5 min, 10 min, 20 min, 30+ min
IntensityLow, Moderate, High
ModeSolo, Pair, Group, Facilitated
Evidence typeSelf-report, peer feedback, performance artifact
Risk profileLow, Medium, Elevated

Progression Rules​

  • Start with low-intensity, low-duration practices.
  • Require consistency before increasing intensity.
  • For shadow practices, progression requires explicit readiness checks.
  • Always provide fallback alternatives and stop rules.

Readiness and Contraindication Markers​

Readiness Markers​

  • Learner can self-monitor distress signals.
  • Learner has completed baseline regulation practices.
  • Learner has demonstrated respectful community participation.

Contraindication Markers​

  • Current acute distress without support plan.
  • Repeated destabilization after reflective practices.
  • Inability to pause or de-escalate during guided exercises.

Practice Cards (Implementation Template)​

Each practice must define:

  • Practice ID
  • Family
  • AQAL tags
  • Duration
  • Intensity
  • Instructions
  • Reflection prompt
  • Evidence capture
  • Safety notes
  • Fallback practice
  • Escalation trigger

Scheduling Guidelines​

  • Pair each concept lesson with one short practice.
  • Insert retrieval prompts 24h, 72h, and 7d after initial exposure.
  • Alternate families across weeks to support interleaving.
  • Keep high-intensity practices facilitator-gated.

Assessment Integration​

  • Use short formative checks for all practice families.
  • Use performance tasks for ethics, relationships, and systems transfer.
  • Use structured reflections for meaning and shadow integration.
  • Require rubric alignment before grading.
