## Self Line Developmental Profile Assessment

The Self line is the most theoretically demanding developmental line on the AQAL map — because the Self line is precisely the line that organises and interprets all the others, including this assessment itself. Cook-Greuter's research (2004, 2013) demonstrates that sentence completion methodology is significantly more valid for ego development assessment than standard self-report questionnaires, because it bypasses the stage-flattering selection bias inherent in multiple-choice formats.

This interactive tool adapts that methodology for a web-based context using a hybrid approach:

- **Section A — Scenario-Based Meaning-Making:** Ten scenarios presenting interpersonal, moral, and identity challenges. For each, you select the response that feels most natural. Your pattern of responses reveals the meaning-making structure that most often organises your experience, mapped onto Cook-Greuter's action-logics across the conventional-postconventional arc.
- **Section B — Sentence Completion Reflection:** Eight open-ended sentence stems that you complete in your own words. After submitting, you are shown a rubric describing how different developmental orientations typically complete each stem — not as a score, but as a reflective mirror and set of interpretive questions.

The results page provides a meaning-making profile (Section A), a reflection guide (Section B), top-3 module recommendations, and explicit context about the limits of self-report for ego development assessment.

:::note Formal Assessment
The **Washington University Sentence Completion Test (WUSCT)**, developed by Jane Loevinger and extended by Susanne Cook-Greuter, is the rigorously validated instrument for ego development assessment. It is available through certified practitioners. This tool is a self-guided reflection aid, not a substitute for the WUSCT.
:::
