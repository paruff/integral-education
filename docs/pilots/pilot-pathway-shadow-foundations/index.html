Pilot Pathway B: Shadow Integration Foundations (4 Weeks)

Audience: adult learners ready for low-to-moderate intensity shadow practices with clear safety scaffolding.

Mandatory Safety Conditions​

  • Explicit consent required before each shadow sequence.
  • Tier 1 default; Tier 2 only with facilitator oversight.
  • Tier 3 excluded from this pilot.

Weekly Arc​

WeekFocusSafety TierAssessment
1Shadow literacy and projection basicsTier 1Reflection quality check
2Trigger patterns and reactivity mappingTier 1Trigger-to-need mapping task
3Role reversal and perspective repairTier 1-2Structured dialogue artifact
4Integration plan and boundary settingTier 1-2Personal integration protocol

Microlearning and Retrieval Pattern​

  • Each week has 5-7 short lessons (3-5 min each).
  • Retrieval loops at 24h, 72h, and 7d on safety cues and core concepts.
  • Weekly mixed-topic interleaving includes emotion labeling, projection spotting, and repair language.

Core Practice Flow​

  1. Consent check and readiness scan.
  2. Practice briefing with contraindications.
  3. Timed activity (5-10 min).
  4. Grounding protocol.
  5. Reflection capture.
  6. Optional peer dialogue (with netiquette protocol).

Example Performance-Based Assessment​

Task: Create a personal "trigger-to-integration" protocol for one recurring interpersonal pattern.

Rubric dimensions:

  • Pattern clarity
  • Emotional differentiation
  • Safety and stop-rule integration
  • Behavior change feasibility

Facilitator Requirements for Pilot B​

  • Tier 2 certified facilitator available for escalation windows.
  • Incident monitoring during all synchronous activities.
  • Documented follow-up protocol for adverse responses.
