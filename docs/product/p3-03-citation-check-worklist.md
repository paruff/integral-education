## How to use

Tier A is the strongest claim the platform makes, so it is checked first. For each row: open the module's Evidence and Citations table, find the source, and confirm (1) the source exists as cited, (2) it supports the claim as worded, (3) Tier A is justified (primary research, replicated), (4) the stated caveat is fair. Mark the last column `ok`, `downgrade to B/C`, or `fix wording`, and note changes. Never replace a citation from memory or from an AI model: look up the source.

Then spot-check at least 10% of Tier B and C tags the same way (a downgrade is not needed for C, but a C that is really an A claim is a wording problem).
